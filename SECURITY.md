# Security Policy

## Supported Versions

OpenBlue does not yet have a stable release.

Security fixes currently target the latest code on `main` and, after releases begin, the latest published release.

## Reporting a Vulnerability

Do not disclose vulnerability details in a public issue, discussion, pull request, or commit message.

Use GitHub private vulnerability reporting for this repository to submit the affected component, reproduction steps, impact, and any suggested mitigation.

If private vulnerability reporting is unavailable, open a public issue that requests a private reporting channel without including sensitive details.

Reports involving microphone access, audio disclosure, virtual device privilege boundaries, update integrity, code signing, configuration corruption, or credential exposure are especially important.

The maintainer will acknowledge a report, investigate it, and coordinate disclosure after a fix or mitigation is available.
